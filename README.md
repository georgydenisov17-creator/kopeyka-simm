# 🚗 Симулятор Копейки

Аркадная 3D-игра на Three.js: рассекай по серому провинциальному городу
на тюнингованной ВАЗ-2101, сбивай бабушек, качай машину.

Проект состоит из 4 файлов, никаких сборок и npm — чистый ES-модуль + CDN.

## 📁 Структура

- `index.html` — разметка интерфейса (меню, HUD, прокачка, настройки) и подключение модулей.
- `style.css` — стили экранов, кнопок, панелей и HUD.
- `game.js` — вся игровая логика: генерация города и текстур, модель ВАЗ-2101, NPC, физика, камеры, Web Audio API, сохранение в `localStorage` и цикл рендера.
- `README.md` — описание проекта и структура файлов.
